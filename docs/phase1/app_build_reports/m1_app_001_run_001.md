## 运行时问题与修正

首次 `app_smoke` 触发 Qt 平台插件错误：

```text
Could not find the Qt platform plugin "minimal"
```

根因：

```text
当前构建链接 Debug Qt: Qt6Cored.dll。
必须使用 debug Qt platform plugin: qminimald.dll。
```

修正：

```text
CTest 的 app_smoke 设置：
QT_QPA_PLATFORM=minimal
QT_QPA_PLATFORM_PLUGIN_PATH=D:/Work/vcpkg/installed/x64-windows/debug/Qt6/plugins/platforms
```

同时已在 `app/CMakeLists.txt` 中加入 post-build 复制：

```text
build/platforms/qminimald.dll
```

因此当前 `build/tsrebar_app.exe --smoke` 已可在 build 目录直接启动退出。
